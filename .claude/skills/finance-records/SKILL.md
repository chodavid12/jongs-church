# 재정·살림 데이터

모든 재정 데이터는 `finance.html`(재정·살림)에 자동 표시된다. JSON은 **손으로 고치지 말고 스크립트로** 입력한다.

## 1. 주간 헌금 (finance.json)
```bash
node scripts/set-finance.mjs <YYYY-MM-DD> <일반> <목적> <구제> ["메모"]
```
- 날짜 = 표의 주간 **시작 일요일** ("09/27-10/03" → `2026-09-27`). 같은 날짜면 덮어쓰기.
- 주보 날짜와 헌금 주간은 다르다: 10/11 주보에는 보통 10/04 주차가 새로 실린다. 밀린 주가 2개 이상일 수 있으니 finance.json 최신 날짜 이후 **모든 완료 주차**를 입력한다.
- 숫자가 비어 있는 주(당주·미래)는 입력하지 않는다. 헌금 **수입만** 기록(지출·잔액 제외).
- 목적헌금 용도가 있으면 메모로 (`"목적: 태국 지원"`).

### 검산 (필수)
입력 전, 표의 주간 값 합계가 **월 합계**와 맞는지 확인한다. 안 맞으면 숫자를 잘못 읽은 것 → 속장을 다시 확대해 읽는다(예: 521,591 → 실제 521,291). 그래도 애매하면 추측하지 말고 사용자에게 묻는다.

### 연합계가 주보와 다른 이유 (정상)
교회 주보의 연합계는 **2026-05-03 주차(621,214원)를 누적에서 누락**한 뒤로 어긋나 있고, 이후에도 주보 쪽 누계가 들쭉날쭉하다. **웹(finance.json)이 정답**이며 사용자도 그렇게 결정했다. 주간 값만 정확히 맞추면 되고, 연합계를 주보에 맞추려고 데이터를 바꾸지 않는다. 구제·목적 누계는 대체로 주보와 일치하므로 교차 확인용으로 쓴다.

## 2. 전기요금 등 공과금 (utilities.json)
```bash
node scripts/set-utility.mjs electric <YYYY> <월> <요금> <전력kWh>
```
- 연도×월 표로 표시되고, 올해 열은 비어 있어도 자동 표시된다. 콤마·'원'·'kWh' 붙여도 처리됨.
- 다른 공과금 종류는 첫 인자를 바꾸면 utilities.json에 새 배열로 저장되지만, 화면 렌더는 현재 `electric`만 한다(추가 시 finance.html 렌더 코드도 확장 필요).

## 3. 반기 재정보고서·기타 자료 (finance-docs/)
- 반기 보고서: `finance-docs/반기/2026-상반기.pdf` 형식으로 넣는다.
- 공과금 증빙 등: `finance-docs/공과금/2026-07-전기세.pdf` 형식 (있을 때만 "기타 공과금 자료"로 표시).
- 넣은 뒤 `node scripts/build-finance-docs.mjs` → finance-docs.json 생성. 파일명의 `상반기/하반기`·`YYYY-MM`으로 기간을 자동 인식.

## 4. 마무리
`node -e "require('./finance.json')"`로 문법 확인 → 커밋 → `main` push → pages 배포 success 확인.
